Low-SWaP-Cost Passive Slotted Waveguide Array Antenna Design & Simulation

Objectives

Design and simulate a 12 GHz passive slotted waveguide array antenna for satellite and SAR applications using MATLAB Antenna Toolbox.

Outcomes & Contributions

Diagnosed simulation bottlenecks, identified computing limitations, and developed a workaround using multi-core parallel processing and an optimized coaxial probe feed.

Technical Details & Math Applications

  • Optimized beam pattern for -20dB sidelobe suppression relative to the main lobe using least-squares method in MATLAB.
  • Computed the physical parameters of a slotted waveguide array and constructed a 3D CAD model using a reference schematic.
  • Integrated a coaxial probe feed into the 3D model.
  • Optimized the coaxial probe feed geometry (3 DOF) for -14 dB return loss level at 12 GHz using a minimizing cost function in MATLAB.
  • Simulated the 3D model’s beam pattern using the MATLAB Antenna Toolbox, took a 2D slice, validated beam pattern, found a peak sidelobe distortion at -18dB.
  • Calculated the S-parameters of the 3D model using MATLAB Antenna Toolbox.
  • Analyzed S11 return loss plot to verify coaxial probe feed impedance matching, found -14 dB return loss level at 12 GHz and 75 MHz bandwidth around 12 GHz at a -14 dB return loss level

Satellite Constellation Solar Power Modeling Under Earth Occultation

Objectives

Model how Earth shadowing affects solar power generation for a low-orbit satellite constellation.

Outcomes & Contributions

Simulated a 3-plane, 9-satellite constellation over 10 days and found that satellites avoiding Earth’s shadow received about 13% more power on average.

Technical Details & Math Applications

  • Navigated a custom multi-body orbital mechanics simulator and worked with tensor modeled satellite constellation variables in MATLAB.
  • Modeled Solar irradiance as a function of distance using the inverse-square law for radiation in MATLAB.
  • Modeled solar panel power using: satellite location, sunlight intensity, solar panel efficiency and panel angle in MATLAB.
  • Calculated Earth’s shadow (umbra and penumbra) from the Sun using vector geometry and trigonometry in MATLAB.
  • Implemented logic algorithm to determine when a satellite is within Earth's shadow using vector geometry in MATLAB.

Modeling Uni-Cellular Organism Movement Using a Hidden Markov Chain

Objectives

Develop a stochastic process framework to predict long-term, multi-directional organism movement behavior.

Outcomes & Contributions

Built a scalable Hidden Markov Model with boundary conditions and generalized transition matrices for arbitrary state spaces and angular variations.

Technical Details & Math Applications

  • Simulated initial organism movement with a random walk using recursive equations in MATLAB.
  • Translated organism’s movement as state transitions using: Markov chain property, momvement direction and turn angle random variables.
  • Implemented boundary movement logic using realistic boundary conditions in MATLAB.
  • Generalized the transition matrix entires using probabilistic sum in MATLAB.
  • Analyzed the long-term behavior of the Markov chain using eigenvalue analysis in MATLAB.

Ramsey Theory

Objectives

Study how different labelings of integer arrays influence the number of rainbow solutions to arithmetic equations. The goal was to identify labeling strategies that optimize solution counts and support theoretical bounds in arithmetic Ramsey theory.

Outcomes & Contributions

Built Python programs to search large arrays, count valid solutions, and analyze convergence patterns. Proved a supporting lemma for a faculty research paper and presented the results at four undergraduate research symposiums.

Technical Details & Math Applications

  • Built an algorithm to count the number of solutions using modular arithmetic and algebra in Python.
  • Built an optimization algorithm to maximize the number of solutions using algebraic logic in Python.
  • Tested optimization algorithm on very large array sizes, found convergence labeling.
  • Rigorously proved findings using modular arithmetic, discrete probability and combinatorics
  • Communicated findings in an academic poster at 4 undergraduate research symposiums.
  • Collaborated with faculty on their research paper.
  • Proved Lemma 2.5: fully reduced equations of the form ax + by = cz have n² solutions over modular integer sets, using number theory, combinatorics, and modular arithmetic.
